# AEGIS Privacy Policy & Data Handling

## 1. Minimal Data Ingestion
AEGIS only processes information visible to any regular visitor of an e-commerce listing:
- Product Title
- Listed Price & Discount
- Public Merchant Profile Details
- Public Customer Reviews
- Product Technical Specifications

## 2. Explicit User Consent
AEGIS enforces a strict consent gate:
- Scans are never initiated silently.
- On first visit to a supported store, AEGIS presents an explicit permission prompt.
- Users can pause scanning, disable auto-scan, or revoke site authorization at any time in the Settings console.

## 3. Data Deletion
Users retain full control of their analysis records:
- Single-click "Clear All Stored Analyses" wipes all cached snapshots and local telemetry.
